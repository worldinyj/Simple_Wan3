# Grok Imagine / new-case production quick reference (2026-10-24)

New cases: 9:16 vertical, 6s clips, 480p supported preset, approximately 20 clips for ~120s. User requested 460p but published presets list 480p, 720p, 1080p. Verify live UI and mode before generating.

Mandatory order: report evidence and uncertainty log; 20-scene storyboard; user-approved character/location/equipment masters; shot-level reference locking; 6-second generation; cross-clip spatial/subject/geometry QC; silent assembly; separate narrator/BGM; final human acceptance.

For every shot keep CHAR/LOC/EQ IDs, outfit, scale, props, pipe routing and camera axis consistent. Preserve approved reference sheets and last-frame continuity. Reject mechanical morphing and side-by-side image boards. Use controlled caption overlays for technical labels. Do not assume prompt alone ensures identity.

Public GitHub: process documents only. Reports, facility identity, and all image/video/audio stay in local media, never public repo. Historical CASE-001–004 files and approvals remain unchanged.

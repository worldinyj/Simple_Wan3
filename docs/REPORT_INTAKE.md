# Incident report intake — keep source private

Input may be PDF/HWP/text; share in chat for analysis, not by pushing restricted files to public GitHub.

Extract:
1. Incident title/date and plant names only when publication is explicitly authorized.
2. Verified timeline: trigger → detection → personnel action → outcome.
3. Confirmed equipment, physical constraints and operator positions.
4. Unknowns/contradictions; do not fill gaps with creative guesses.
5. Learning point and a concise viewer takeaway.
6. Candidate shots and what can be drawn as simplified miniatures.

For every shot classify **FACT**, **INTERPRETATION**, **RECONSTRUCTION**, or **EDUCATIONAL**. State clearly when generic explanatory staging is used. Hide confidential drawings, serial numbers, personal data and facility-specific security details. Use public-safe abstractions in this public repository.
